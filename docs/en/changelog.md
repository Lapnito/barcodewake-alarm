# BarcodeWake documentation changelog

This changelog records documentation evidence, not a promise that each source capability has reached every app store. Public store versions and the checked source version remain separate until a matching release is independently verified.

## September 2026 documentation baseline

- Created an English documentation set from the checked Flutter source, privacy policy and public Google Play snapshot.
- Recorded Google Play version 1.0.0 separately from source version 2.0.0+2.
- Documented barcode, QR, maths, typing, shake and step missions found in current source.
- Documented single, chain and random mission modes as source capabilities.
- Added local storage, code hashing, optional telemetry and no-account boundaries.
- Added JSON backup, printable PDF backup barcode and limited setup QR distinctions.
- Added permission, battery and vendor-control troubleshooting without promising guaranteed delivery.
- Withheld a public iOS availability claim because no verified App Store listing was available.
