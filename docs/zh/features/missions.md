# BarcodeWake 任务和任务链

BarcodeWake 任务是用于关闭闹钟的条件。当前支持的来源包括条形码、二维码、数学、打字、摇晃和步数任务，已注册的 NFC 通过代码扫描路径处理。任务可以单独运行、按顺序运行或随机选择运行。

## 扫描任务创造物理距离

条形码或二维码任务会将实时相机扫描与设置期间注册的代码进行比较。该代码可以放置在手臂够不到的地方的物品上：浴室里的洗漱用品、厨房里的早餐食品，或者光线充足区域的其他稳定物品。NFC 通过兼容标签和设备遵循相同的总体思路。应用程序在当前路径中存储哈希表示，而不是需要原始代码进行常规比对。

选择一个在闹钟响起时仍然可用的物品。包装会被丢弃，标签会褪色，旅行会改变环境。在唯一可能需要更换的药盒上注册代码，不如使用耐用的标签更稳健。[闹钟设置指南](../guides/set-up-an-alarm.md) 涵盖了放置和测试。

## 挑战任务以运动换取努力

数学和打字需要专注的输入。摇晃和步数需要身体运动和支持的传感器。难度和目标设置会改变所需的工作量，但更难的任务并不自动是更好的任务。过度的摩擦可能会鼓励完全禁用闹钟，而简单的任务在重复后可能会变得自动化。

将任务与失败模式相匹配。如果您在半睡半醒时关闭闹钟，在另一个房间扫描会产生有用的距离。如果相机访问不方便，短时间内打字或数学任务可能更实用。如果有行动能力、平衡或无障碍方面的顾虑，请避免基于运动的任务，选择可以安全完成的任务。

## 单独、链式和随机模式

单独模式要求执行一个已配置的任务。链式模式按顺序运行多个已配置的任务。随机模式从已配置集合中选择，减少一种记忆中的交互变得自动化的可能性。这些模式存在于较新的已检查源代码中；[可用性](../availability.md) 解释了为什么这不能证明它们已在每个公开版本中。

更改模式、权限或注册对象后，请始终进行短期测试。保持所选对象可触及，并提供安全的恢复路线。对于与任务完成无关的交付问题，请使用[可靠性检查清单](../help/alarm-delivery.md)。
