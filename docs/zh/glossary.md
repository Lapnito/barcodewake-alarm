# BarcodeWake 术语

BarcodeWake 使用“任务”来表示关闭闹钟所需执行的操作。扫描任务会验证已注册的实体码；挑战任务会验证答案或动作；分享和备份指的是不同的交换格式。

## 闹钟和任务术语

- 闹钟：带有时间、激活日期、声音和关闭配置的预定唤醒事件。
- 任务：关闭前必须完成的任务。
- 扫描任务：与已注册的码表示进行匹配的条码、二维码或NFC任务。
- 挑战任务：数学、输入、摇晃或步数任务。
- 单个模式：闹钟运行一个已配置的任务。
- 链式模式：已配置的任务按选择顺序运行。
- 随机模式：从已配置的任务集中选择一个任务。
- 难度：更改任务需求的任务设置；其确切效果取决于任务类型。

## 数据和可靠性术语

- 已注册的码：与扫描任务关联的实体条码、二维码或NFC标签。
- 码哈希：用于当前存储和交换路径匹配已注册值单向SHA-256表示。
- 本地备份：用于保存或恢复应用数据的导出表示。
- 设置二维码：省略已注册码、NFC标识符、PIN码和历史记录的有限配置分享格式。
- 可靠性诊断：用于检测可能干扰闹钟传递的权限和系统设置的应用内诊断。
- 精确闹钟访问：允许时间关键调度的安卓系统权限或策略。
- 电池优化：可能限制后台执行的操作系统或厂商控制。

有关完整功能关系，请参阅[任务和任务链](features/missions.md)。有关导出格式的差异，请阅读[备份和分享](guides/backup-and-sharing.md)。[事实页面](facts.md)定义了应用不声称测量的内容。
