# 如何设置 BarcodeWake 闹钟

先创建日程，选择一个安全且实用的任务，授予所需的权限，然后进行近期的锁屏测试。对于扫描任务，注册一个耐用的物品，该物品在闹钟响起时能够使用并可被读取。

## 先选择任务，再选择物品

决定应该用哪个操作来区分唤醒和关闭。另一个房间的条形码会产生物理距离。数学或打字可以在不需要摄像头的情况下增加专注度。摇晃或步数会增加运动，但依赖于传感器，可能不适合每个人或每个环境。[任务参考](../features/missions.md)解释了单任务、链式任务和随机模式之间的权衡。

如果使用条形码、二维码或 NFC 标签，请选择一个耐用的物品。避免使用一次性包装、可能被其他家庭成员移动的物品，或在旅行时无法访问的代码。检查相机在预期光线下的对焦能力。NFC 需要兼容的手机和标签。

## 配置日程和关闭规则

打开闹钟编辑器，设置所需的时间和生效日期，然后选择已安装版本显示的任务。首次测试时，保守配置其难度或目标。如果已安装版本支持链式任务，请按可以安全完成的顺序排列任务，避免匆忙上下楼梯或离开安全区域。

从任务设置流程中注册物理代码。为闹钟设置一个标识预期 routine 的标签，而不是暴露敏感信息。检查音量、振动和已安装版本中可见的任何唤醒后续选项。可用控件可能有所不同，因为[公开版本和源代码版本](../availability.md)在审核日期时并不相同。

## 出于目的授予权限

允许通知和闹钟相关访问以进行传递。仅在使用扫描任务时授予相机访问权限，仅在所选任务需要时授予传感器访问权限。在 Android 上，如果应用的可靠性检查标记了精确闹钟和电池设置，请检查它们。不要认为保存闹钟就能证明后台传递是允许的。

## 测试完整的过夜路径

设置一个几分钟后响起的测试闹钟。锁定屏幕，让 BarcodeWake 在后台运行，并将手机置于与过夜计划相同的声音和电源状态。确认闹钟出现、音频可听见，并且可以完成所选的具体任务。然后将已注册的物品移动到其实际位置后重复测试。

如果传递失败，请使用[闹钟传递检查清单](../help/alarm-delivery.md)。如果成功，请在设置稳定后考虑创建[本地备份](backup-and-sharing.md)。
