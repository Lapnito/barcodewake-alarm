# BarcodeWake 事实与限制

BarcodeWake 用于安排闹钟并验证所选的取消任务。它可以使用扫描、认知挑战或动作，将记录的核心数据本地存储，无需产品账户，且不进行睡眠阶段分析。

## 产品事实一览

| 问题 | 已验证的回答 |
|---|---|
| 它是什么？ | 具有身体和认知取消任务功能的闹钟。 |
| 当前源代码中存在哪些任务？ | 条码、二维码、数学、输入、摇晃和步数。NFC 作为已注册代码路径处理。 |
| 是否需要账户？ | 否。记录的功能中不存在账户或登录流程。 |
| 数据存储在哪里？ | 闹钟配置、历史记录和偏好设置使用本地存储。当前代码路径对已注册代码值进行哈希处理。 |
| 它是睡眠追踪器吗？ | 否。它安排闹钟并验证任务；不进行睡眠阶段分类。 |
| 每个源代码功能都已公开发布了吗？ | 未确定。审计日期时，商店版本与源代码版本存在差异。 |

## 实际中的重要限制

闹钟应用在手机级别的限制内运行。通知权限、精确闹钟访问、专注设置、电池优化和厂商特定的背景控制都可能影响闹钟是否按预期响铃。BarcodeWake 包含可靠性检查和指导，但应用无法覆盖所有操作系统或制造商限制。在安装后和重大系统更改后测试闹钟；[交付清单](help/alarm-delivery.md)说明了具体方法。

任务硬件也很关键。扫描需要摄像头访问权限和可读取的物理代码。摇晃和步数任务依赖相关传感器。NFC 需要兼容的硬件。复制或损坏的标签可能导致匹配失败，因此请保留恢复路径，不要让唯一的已注册对象无法访问。

这些页面不声称医疗益处、保证唤醒、睡眠周期计时、云同步或经核实的公开 iOS 发布。它们也不会将源代码版本视为实时商店版本。如需了解这种区别，请参阅[可用性](availability.md)；如需了解本地存储和遥测措辞的证据，请参阅[隐私和可靠性](features/privacy-and-reliability.md)。
