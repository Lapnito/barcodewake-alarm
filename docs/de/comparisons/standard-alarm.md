# BarcodeWake im Vergleich zu einem Standard-Wecker

BarcodeWake fügt einer geplanten Alarmzeit eine überprüfbare Ausschaltaufgabe hinzu, während ein Standardwecker normalerweise mit einer nahen Steuerung stoppt. Diese zusätzliche Reibung kann automatisches Schlummern unterbrechen, bringt aber auch Einrichtungs-, Hardware- und Barrierefreiheitsaspekte mit sich.

## Der praktische Unterschied liegt beim Ausschalten

Ein herkömmlicher Telefon- oder Nachttischwecker lässt sich schnell einstellen und schnell stumm schalten. Diese Einfachheit ist angemessen, wenn der Ton selbst ausreicht. Sie wird zum Schwachpunkt für jemanden, der Alarme ausschaltet, ohne eine klare Erinnerung daran zu bilden.

BarcodeWake verlagert die Entscheidung in eine Mission. Ein Barcode, der entfernt vom Bett platziert ist, erfordert das Erreichen und Scannen eines Objekts. Mathematik oder Tippen erfordert Aufmerksamkeit. Schütteln oder Schritte erfordern Bewegung. Die aktuelle Quelle kann auch Missionen kombinieren oder eine aus einem Set auswählen. Keine dieser Methoden misst, ob der Benutzer biologisch wach ist; sie verifizieren nur, dass eine definierte Interaktion abgeschlossen wurde.

| Überlegung | BarcodeWake | Standard-Wecker |
|---|---|---|
| Ausschalten | Scan, kognitive Aufgabe oder Bewegung | Normalerweise eine Taste oder Geste |
| Einrichtungsaufwand | Mission, Berechtigungen und Testen | Zeit, Tage und Ton |
| Hardware-Abhängigkeit | Kamera oder Sensoren für einige Missionen | Lautsprecher oder Vibration |
| Automatisches Schlummern Widerstand | Kann Entfernung oder Aufwand erfordern | Normalerweise begrenzt |
| Barrierefreiheit | Mission muss sorgfältig gewählt werden | Einfachere Interaktion |
| Zuverlässigkeitsgrenze | Betriebssystem und Herstellerkontrollen | Gerätestrom und Alarmimplementierung |

## Wählen Sie BarcodeWake für einen spezifischen Fehlermodus

Es ist besser geeignet, wenn das Problem nicht das Hören des Alarms ist, sondern das automatische Ausschalten. Ein stabiler Code in einem anderen Raum schafft einen Kontextwechsel, den ein Rätsel auf dem Bildschirm nicht kann. Eine kognitive Mission kann für Reisen geeignet sein, wo kein dauerhafter physischer Code verfügbar ist. Zufällige oder verkettete Aufgaben können die Gewöhnung reduzieren, wenn die installierte Version sie unterstützt.

Verwenden Sie die [Missionsanleitung](../features/missions.md), um die Aufgabe an die Umgebung anzupassen. Vermeiden Sie Bewegungsmissionen, wenn sie Sturzrisiken schaffen, andere stören oder mit Mobilitätsbedürfnissen kollidieren. Eine anspruchsvolle Aufgabe, die dazu führt, dass die App deaktiviert wird, ist schlimmer als eine bescheidene Aufgabe, die nachhaltig bleibt.

## Behalten Sie einen Standard-Fallback für folgenreiche Morgen

Die missionbasierte Ausschaltung entfernt keine Telefonebene-Fehlermodi. Berechtigungen, Batterieoptimierung, Lautstärke und Herstellereinschränkungen sind weiterhin wichtig. Für Flüge, Arzttermine oder andere folgenreiche Ereignisse verwenden Sie einen zweiten unabhängigen Alarm, bis die Einrichtung unter realen Übernachtungsbedingungen getestet wurde.

Folgen Sie dem [Einrichtungs- und Testverfahren](../guides/set-up-an-alarm.md), behalten Sie dann die [Liefercheckliste](../help/alarm-delivery.md). Wenn ein einfacher Nachttischwecker bereits zuverlässig funktioniert und versehentliches Ausschalten nicht das Problem ist, kann die zusätzliche Reibung von BarcodeWake wenig Nutzen bieten.
