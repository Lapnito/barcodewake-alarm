# BarcodeWake கலைச்சொல்

BarcodeWake ஒரு எச்சரிக்கையை நிராகரிக்க தேவையான செயலுக்கு "அனுப்பம்" என்ற சொல்லைப் பயன்படுத்துகிறது. ஸ்கேன் அனுப்பங்கள் பதிவுசெய்யப்பட்ட இயற்பிய குறியீட்டை சரிபார்க்கின்றன; சவால் அனுப்பங்கள் ஒரு பதிலை அல்லது இயக்கத்தை சரிபார்க்கின்றன; பகிர்தல் மற்றும் காப்புப்பிரதி வெவ்வேறு பரிமாற்ற வடிவங்களைக் குறிக்கின்றன.

## எச்சரிக்கை மற்றும் அனுப்ப சொற்கள்

- Alarm: நேரம், செயலில் உள்ள நாட்கள், ஒலி மற்றும் நிராகரிப்பு அமைப்புடன் கூடிய திட்டமிடப்பட்ட எழுந்திருக்கும் நிகழ்வு.
- Mission: நிராகரிப்பதற்கு முன்பு முடித்திருக்க வேண்டிய பணி.
- Scan mission: பதிவுசெய்யப்பட்ட குறியீடு பிரதிநிதித்துவத்துடன் பொருந்தும் பார்கோடு, QR அல்லது NFC அடிப்படையிலான பணி.
- Challenge mission: கணிதம், தட்டச்சு, அசைவு அல்லது படி பணி.
- Single mode: ஒரு அமைக்கப்பட்ட அனுப்பம் எச்சரிக்கைக்காக இயக்கப்படுகிறது.
- Chain mode: அமைக்கப்பட்ட அனுப்பங்கள் தேர்ந்தெடுக்கப்பட்ட வரிசையில் இயங்குகின்றன.
- Random mode: ஒரு அமைக்கப்பட்ட தொகுப்பிலிருந்து ஒரு அனுப்பம் தேர்ந்தெடுக்கப்படுகிறது.
- Difficulty: பணி தேவையை மாற்றும் அனுப்ப அமைப்பு; அதன் சரியான விளைவு அனுப்ப வகையைப் பொருத்தது.

## தரவு மற்றும் நம்பகத்தன்மை சொற்கள்

- Registered code: ஸ்கேன் அனுப்பத்துடன் தொடர்புடைய இயற்பிய பார்கோடு, QR குறியீடு அல்லது NFC குறிச்சீர்.
- Code hash: பதிவுசெய்யப்பட்ட மதிப்புகளை பொருத்துவதற்கு தற்போதைய சேமிப்பு மற்றும் பரிமாற்ற பாதைகளால் பயன்படுத்தப்படும் ஒரு-திசை SHA-256 பிரதிநிதித்துவம்.
- Local backup: செயலி தரவை பாதுகாக்க அல்லது மீட்டெடுக்க திட்டமிடப்பட்ட ஏற்றுமதி பிரதிநிதித்துவம்.
- Setup QR: பதிவுசெய்யப்பட்ட குறியீடுகள், NFC அடையாளங்காட்டிகள், PINகள் மற்றும் வரலாற்றை தவிர்க்கும் வரையறுக்கப்பட்ட கட்டமைப்பு-பகிர்வு வடிவம்.
- Reliability Doctor: எச்சரிக்கை வழங்கலில் தலையிடக்கூடிய அனுமதிகள் மற்றும் கணினி அமைப்புகளுக்கான செயலி-உள்ளக கருவிகள்.
- Exact-alarm access: நேர-இன்றியமையா திட்டமிடலை அனுமதிக்கும் Android கணினி அனுமதி அல்லது கொள்கை.
- Battery optimisation: பின்னணி செயல்பாட்டை வரையறுக்கக்கூடிய இயக்கமைப்பு அல்லது விற்பனையாளர் கட்டுப்பாடுகள்.
