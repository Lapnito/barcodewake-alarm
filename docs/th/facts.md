# ข้อเท็จจริงและข้อจำกัดของ BarcodeWake

BarcodeWake กำหนดเวลาปลุกและตรวจสอบภารกิจการปลุกที่เลือก โปรแกรมสามารถใช้การสแกน ความท้าทายทางปัญญา หรือการเคลื่อนไหว จัดเก็บข้อมูลหลักที่บันทึกไว้ในเครื่อง ไม่ต้องมีบัญชีผลิตภัณฑ์ และไม่ทำการวิเคราะห์ระดับการนอนหลับ

## ข้อเท็จจริงของผลิตภัณฑ์ในภาพรวม

| คำถาม | คำตอบที่ตรวจสอบแล้ว |
|---|---|
| มันคืออะไร? | นาฬิกาปลุกพร้อมภารกิจการปลุกทั้งทางกายภาพและทางปัญญา |
| มีภารกิจอะไรบ้างในซอร์สโค้ดปัจจุบัน? | บาร์โค้ด, QR, คณิตศาสตร์, พิมพ์, เขย่า และเดิน NFC ถูกจัดการเป็นเส้นทางโค้ดที่ลงทะเบียน |
| ต้องมีบัญชีหรือไม่? | ไม่มีบัญชีหรือขั้นตอนการลงชื่อเข้าใช้สำหรับฟีเจอร์ที่บันทึกไว้ |
| ข้อมูลถูกเก็บไว้ที่ไหน? | การตั้งค่าปลุก ประวัติ และการต้องการใช้ที่เก็บข้อมูลในเครื่อง เส้นทางโค้ดปัจจุบันแฮชค่าโค้ดที่ลงทะเบียน |
| มันเป็นติดตามการนอนหรือไม่? | ไม่ โปรแกรมกำหนดเวลาปลุกและตรวจสอบภารกิจ ไม่ทำการจำแนกระดับการนอนหลับ |
| ทุกฟีเจอร์ในซอร์สโค้ดเปิดให้บริการสาธารณะแล้วหรือยัง? | ไม่ได้รับการยืนยัน รุ่นในร้านค้าและซอร์สโค้ดมีความแตกต่างกัน ณ วันที่ตรวจสอบ |

## ข้อจำกัดที่สำคัญในทางปฏิบัติ

แอปปลุกทำงานภายใต้ข้อจำกัดระดับโทรศัพท์ สิทธิ์การแจ้งเตือน การเข้าถึงปลุกตรงเวลา การตั้งค่าโฟกัส การปรับแต่งแบตเตอรี่ และการควบคุมพื้นหลังเฉพาะผู้ผลิต ล้วนส่งผลต่อการมาถึงของการปลุกตามที่คาดหวัง BarcodeWake มีการตรวจสอบความน่าเชื่อถือและคำแนะนำ แต่แอปไม่สามารถแทนที่ทุกข้อจำกัดของระบบปฏิบัติการหรือผู้ผลิตได้ ทดสอบการปลุกหลังติดตั้งและหลังการเปลี่ยนแปลงระบบครั้งใหญ่ รายการตรวจสอบการจัดส่ง [delivery checklist](help/alarm-delivery.md) อธิบายวิธีการ

ฮาร์ดแวร์ภารกิจก็มีความสำคัญเช่นกัน การสแกนต้องการสิทธิ์กล้องและโค้ดกายภาพที่อ่านได้ ภารกิจเขย่าและเดินขึ้นอยู่กับเซนเซอร์ที่เกี่ยวข้อง NFC ต้องการฮาร์ดแวร์ที่รองรับ ฉลากที่คัดลอกหรือเสียหายอาจป้องกันการจับคู่ ดังนั้นควรมีวิธีกู้คืนและอย่าทำให้วัตถุที่ลงทะเบียนเพียงอย่างเดียวเข้าถึงไม่ได้

## ข้ออ้างที่ตั้งใจไม่ทำ

หน้าเหล่านี้ไม่อ้างว่าได้รับประโยชน์ทางการแพทย์ การตื่นที่รับประกัน การจับเวลาวงจรการนอน การซิงโครไนซ์คลาวด์ หรือการเปิดให้บริการ iOS สาธารณะที่ตรวจสอบแล้ว หน้าเหล่านี้ยังไม่ถือว่ารุ่นซอร์สโค้ดเป็นรุ่นร้านค้าสด ดู [ความพร้อมให้บริการ](availability.md) สำหรับความแตกต่างนี้ และ [ความเป็นส่วนตัวและความน่าเชื่อถือ](features/privacy-and-reliability.md) สำหรับหลักฐานเบื้องหลังการจัดเก็บข้อมูลในเครื่องและคำศัพท์เรื่องการรวบรวมข้อมูล
