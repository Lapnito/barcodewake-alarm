# ศัพท์เฉพาะของ BarcodeWake

BarcodeWake ใช้คำว่า "mission" สำหรับการดำเนินการที่จำเป็นในการปิดเสียงปลุก ภารกิจสแกนจะตรวจสอบรหัสกายภาพที่ลงทะเบียนไว้ ภารกิจท้าทายจะตรวจสอบคำตอบหรือการเคลื่อนไหว การแชร์และการสำรองข้อมูลหมายถึงรูปแบบการแลกเปลี่ยนที่แตกต่างกัน

## คำศัพท์เกี่ยวกับเสียงปลุกและภารกิจ

- ปลุก: เหตุการณ์ตื่นตามกำหนดเวลาพร้อมเวลา วันที่ใช้งาน เสียง และการตั้งค่าการปิดเสียง
- ภารกิจ: งานที่ต้องทำให้เสร็จก่อนปิดเสียง
- ภารกิจสแกน: ภารกิจที่ใช้บาร์โค้ด คิวอาร์ หรือเอ็นเอฟซี ซึ่งจับคู่กับการแสดงรหัสที่ลงทะเบียนไว้
- ภารกิจท้าทาย: งานทางคณิตศาสตร์ การพิมพ์ การเขย่า หรือการก้าว
- โหมดเดียว: ภารกิจที่กำหนดค่าไว้หนึ่งภารกิจทำงานสำหรับเสียงปลุก
- โหมดเชน: ภารกิจที่กำหนดค่าไว้ทำงานตามลำดับที่เลือก
- โหมดสุ่ม: ภารกิจหนึ่งภารกิจถูกเลือกจากชุดที่กำหนดค่าไว้
- ความยาก: การตั้งค่าภารกิจที่เปลี่ยนความต้องการของงาน ผลกระทบที่แท้จริงขึ้นอยู่กับประเภทของภารกิจ

## คำศัพท์เกี่ยวกับข้อมูลและความน่าเชื่อถือ

- รหัสที่ลงทะเบียน: บาร์โค้ดกายภาพ คิวอาร์โค้ด หรือแท็กเอ็นเอฟซีที่เชื่อมโยงกับภารกิจสแกน
- แฮชรหัส: การแสดงแบบทางเดียว SHA-256 ที่ใช้โดยเส้นทางการจัดเก็บและการแลกเปลี่ยนปัจจุบันสำหรับการจับคู่ค่าที่ลงทะเบียนไว้
- การสำรองข้อมูลในเครื่อง: การแสดงผลที่ส่งออกเพื่อรักษาหรือกู้คืนข้อมูลแอป
- คิวอาร์ตั้งค่า: รูปแบบการแชร์การตั้งค่าที่จำกัดซึ่งไม่รวมรหัสที่ลงทะเบียน ตัวระบุเอ็นเอฟซี พิน และประวัติ
- แพทย์ความน่าเชื่อถือ: การวินิจฉัยในแอปสำหรับการอนุญาตและการตั้งค่าระบบที่อาจรบกวนการส่งเสียงปลุก
- การเข้าถึงการปลุกตรงเวลา: การอนุญาตหรือนโยบายระบบ Android ที่อนุญาตการจัดตารางเวลาที่สำคัญ
- การปรับให้เหมาะสมแบตเตอรี่: การควบคุมระบบปฏิบัติการหรือผู้ผลิตที่อาจจำกัดการทำงานเบื้องหลัง

สำหรับความสัมพันธ์ของฟีเจอร์ทั้งหมด ดู [ภารกิจและห่วงโซ่ภารกิจ](features/missions.md) สำหรับความแตกต่างระหว่างรูปแบบการส่งออก ให้อ่าน [การสำรองข้อมูลและการแชร์](guides/backup-and-sharing.md) [หน้าข้อเท็จจริง](facts.md) กำหนดสิ่งที่แอปไม่อ้างว่าวัด
