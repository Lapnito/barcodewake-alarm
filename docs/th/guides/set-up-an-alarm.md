# วิธีตั้งค่าการปลุก BarcodeWake

สร้างตารางเวลาก่อน เลือกภารกิจที่ปลอดภัยและใช้งานได้จริง ให้สิทธิ์ที่จำเป็น แล้วทดสอบแบบล็อกหน้าจอในระยะใกล้ สำหรับภารกิจสแกน ให้ลงทะเบียนวัตถุที่ทนทานซึ่งจะพร้อมใช้และอ่านได้เมื่อนาฬิกาปลุกดังขึ้น

## เลือกภารกิจก่อนวัตถุ

ตัดสินใจว่าการกระทำใดควรแยกการตื่นจากการปิด บาร์โค้ดในห้องอื่นสร้างระยะทางทางกายภาพ คณิตศาสตร์หรือพิมพ์เพิ่มความตั้งใจโดยไม่ต้องใช้กล้อง เขย่าหรือก้าวเพิ่มการเคลื่อนไหวแต่ขึ้นอยู่กับเซ็นเซอร์และอาจไม่เหมาะกับทุกคนหรือสภาพแวดล้อม คู่มือ [ข้อมูลอ้างอิงภารกิจ](../features/missions.md) อธิบายข้อแลกเปลี่ยนระหว่างโหมดเดี่ยว สาย และสุ่ม

หากใช้บาร์โค้ด คิวอาร์โค้ด หรือแท็ก NFC ให้เลือกสิ่งที่ทนทาน หลีกเลี่ยงบรรจุภัณฑ์ใช้แล้วทิ้ง วัตถุที่สมาชิกครอบครัวคนอื่นอาจย้าย หรือโค้ดที่เข้าถึงไม่ได้ระหว่างเดินทาง ตรวจสอบว่ากล้องสามารถโฟกัสได้ภายใต้แสงที่คาดหวัง NFC ต้องการโทรศัพท์และแท็กที่รองรับ

## ตั้งค่าตารางเวลาและกฎการปิด

เปิดตัวแก้ไขการปลุก ตั้งเวลาที่ต้องการและวันที่เปิดใช้งาน จากนั้นเลือกภารกิจที่แสดงโดยบิวด์ที่ติดตั้ง ตั้งค่าความยากหรือเป้าหมายอย่างระมัดระวังสำหรับการทดสอบครั้งแรก หากเวอร์ชันที่ติดตั้งรองรับสาย ให้จัดลำดับภารกิจเพื่อให้สามารถทำเสร็จได้อย่างปลอดภัยโดยไม่ต้องรีบผ่านบันไดหรือออกจากพื้นที่ปลอดภัย

ลงทะเบียนโค้ดกายภาพจากขั้นตอนการตั้งค่าภารกิจ ให้ป้ายกำกับการปลุกที่ระบุกิจวิธีที่ตั้งใจไว้แทนที่จะเปิดเผยข้อมูลที่ละเอียดอ่อน ตรวจสอบระดับเสียง การสั่น และตัวเลือกการติดตามหลังตื่นที่แสดงในบิวด์ที่ติดตั้ง ตัวควบคุมที่มีอาจแตกต่างกันเพราะ [เวอร์ชันสาธารณะและซอร์ส](../availability.md) ไม่เหมือนกันในวันที่ตรวจสอบ

## ให้สิทธิ์ตามจุดประสงค์

อนุญาตการแจ้งเตือนและการเข้าถึงที่เกี่ยวข้องกับการปลุกเพื่อให้ส่งได้ ให้สิทธิ์เข้าถึงกล้องเฉพาะเมื่อใช้ภารกิจสแกน และสิทธิ์เข้าถึงเซ็นเซอร์เมื่อภารกิจที่เลือกต้องการ บน Android ให้ตรวจสอบการตั้งค่าการปลุกตรงเวลาและแบตเตอรี่หากการตรวจสอบความน่าเชื่อถือของแอปแจ้งเตือน อย่าสันนิษฐานว่าการบันทึกการปลุกพิสูจน์ว่าการส่งในพื้นหลังได้รับอนุญาต

## ทดสอบเส้นทางการปลุกตลอดคืนแบบครบวงจร

ตั้งการทดสอบไว้สักไม่กี่นาทีข้างหน้า ล็อกหน้าจอ ปล่อยให้ BarcodeWake อยู่ในพื้นหลัง และวางโทรศัพท์ในสถานะเสียงและพลังงานเดียวกับที่วางแผนไว้สำหรับการนอนคืน ยืนยันว่าการปลุกปรากฏ เสียงได้ยิน และภารกิจที่เลือกไว้สามารถทำเสร็จได้ จากนั้นทำซ้ำหลังย้ายวัตถุที่ลงทะเบียนไว้ไปยังตำแหน่งจริง

หากการส่งล้มเหลว ให้ใช้ [รายการตรวจสอบการส่งการปลุก](../help/alarm-delivery.md) หากสำเร็จ พิจารณาทำ [สำรองข้อมูลภายใน](backup-and-sharing.md) หลังจากการตั้งค่าเสถียร
