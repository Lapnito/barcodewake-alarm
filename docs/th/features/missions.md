# มิชชั่นและห่วงโซ่มิชชั่นของ BarcodeWake

มิชชั่นของ BarcodeWake คือเงื่อนไขที่ใช้ในการยกเลิกการปลุก แหล่งข้อมูลปัจจุบันรองรับงานแบบบาร์โค้ด, QR, คณิตศาสตร์, พิมพ์, เขย่า และก้าว โดย NFC ที่ลงทะเบียนแล้วจะถูกจัดการผ่านเส้นทางสแกนโค้ด มิชชั่นอาจทำงานเดี่ยว เป็นลำดับ หรือเลือกแบบสุ่ม

## มิชชั่นสแกนสร้างระยะทางทางกายภาพ

มิชชั่นบาร์โค้ดหรือ QR จะเปรียบเทียบการสแกนจากกล้องแบบเรียลไทม์กับโค้ดที่ลงทะเบียนไว้ระหว่างการตั้งค่า โค้ดสามารถวางบนวัตถุที่อยู่นอกระยะที่เอื้อมถึงได้: เครื่องใช้ในห้องน้ำในห้องน้ำ, อาหารเช้าในครัว, หรือวัตถุที่มั่นคงในที่ที่มีแสงเพียงพอ NFC ก็ใช้แนวคิดเดียวกันโดยใช้แท็กและอุปกรณ์ที่รองรับ แอปจะเก็บแฮชของโค้ดไว้ในเส้นทางปัจจุบันแทนที่จะต้องใช้โค้ดดิบสำหรับการเปรียบเทียบปกติ

เลือกวัตถุที่ยังคงมีอยู่เมื่อการปลุกดังขึ้น บรรจุภัณฑ์ถูกทิ้ง ฉลากซีดและการเดินทางเปลี่ยนสภาพแวดล้อม การลงทะเบียนโค้ดบนกล่องยาที่คุณอาจต้องเปลี่ยนเป็นวิธีที่มีความทนทานน้อยกว่าการใช้ฉลากที่ทนทาน [คู่มือตั้งค่าปลุก](../guides/set-up-an-alarm.md) ครอบคลุมการวางตำแหน่งและการทดสอบ

## มิชชั่นท้าทายแลกเปลี่ยนการเคลื่อนไหวเพื่อความพยายาม

คณิตศาสตร์และการพิมพ์ต้องการการให้ข้อมูลที่จดจ่อ เขย่าและก้าวต้องการการเคลื่อนไหวทางกายภาพและเซ็นเซอร์ที่รองรับ การตั้งค่าระดับความยากและเป้าหมายจะเปลี่ยนปริมาณงานที่คาดหวัง แต่มิชชั่นที่ยากกว่าไม่ได้หมายความว่าดีกว่าโดยอัตโนมัติ แรงเสียดทานมากเกินไปอาจทำให้ปิดการปลุกทั้งหมด ในขณะที่งานที่ง่ายอาจกลายเป็นอัตโนมัติหลังจากทำซ้ำ

จับคู่งานกับโหมดความล้มเหลว หากคุณปิดการปลุกในขณะที่หลับไม่สนิท การสแกนในห้องอื่นจะสร้างระยะทางที่เป็นประโยชน์ หากการเข้าถึงกล้องไม่สะดวก งานพิมพ์หรือคณิตศาสตร์สั้นๆ อาจเหมาะสมกว่า หากมีปัญหาเกี่ยวกับการเคลื่อนไหว, การทรงตัว หรือการเข้าถึง ให้หลีกเลี่ยงมิชชั่นที่ใช้การเคลื่อนไหว และเลือกงานที่สามารถทำได้อย่างปลอดภัย

## โหมดเดียว, ห่วงโซ่ และสุ่ม

โหมดเดียวจะขอมิชชั่นที่กำหนดค่าไว้หนึ่งรายการ โหมดห่วงโซ่จะเรียกใช้มิชชั่นหลายรายการตามลำดับ โหมดสุ่มจะเลือกจากชุดที่กำหนดค่าไว้ ลดโอกาสที่การโต้ตอบที่จดจำไว้จะกลายเป็นอัตโนมัติ โหมดเหล่านี้มีอยู่ในแหล่งข้อมูลที่ตรวจสอบเวอร์ชันใหม่กว่า [ความพร้อม](../availability.md) อธิบายว่าทำไมสิ่งนี้ไม่ได้พิสูจน์ว่าพวกมันมีอยู่ในทุกเวอร์ชันสาธารณะแล้ว

เมื่อเปลี่ยนโหมด, สิทธิ์ หรือวัตถุที่ลงทะเบียน ควรทำการทดสอบในระยะใกล้ทุกครั้ง รักษาวัตถุที่เลือกให้เข้าถึงได้และจัดเส้นทางการกู้คืนที่ปลอดภัย สำหรับปัญหาการส่งมอบที่ไม่เกี่ยวข้องกับการทำมิชชั่นเสร็จสิ้น ให้ใช้ [รายการตรวจสอบความน่าเชื่อถือ](../help/alarm-delivery.md)
