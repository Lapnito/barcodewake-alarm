# ความเป็นส่วนตัวและความน่าเชื่อถือของการแจ้งเตือน BarcodeWake

BarcodeWake เก็บข้อมูลการกำหนดค่าการแจ้งเตือนที่บันทึกไว้และข้อมูลภารกิจไว้ในอุปกรณ์ และไม่ต้องการบัญชีแอป พาธโค้ดปัจจุบันจะแฮชค่าโค้ดที่ลงทะเบียนไว้ การวิเคราะห์แบบเลือกได้อธิบายว่าปิดอยู่โดยค่าเริ่มต้น ในขณะที่การส่งการแจ้งเตือนยังคงขึ้นอยู่กับสิทธิ์ของระบบและการควบคุมของผู้ผลิต

## ข้อมูลในเครื่องไม่ได้ลบการพึ่งพาระบบออก

การจัดเก็บข้อมูลในเครื่องหมายความว่าการตั้งค่าการแจ้งเตือนทั่วไปไม่ต้องการบัญชีคลาวด์ของ BarcodeWake บันทึกการแจ้งเตือน ประวัติ และการตั้งค่า จะถูกจัดการผ่านชั้นข้อมูลในเครื่องของแอป ค่าบาร์โค้ด QR และ NFC ที่ลงทะเบียนจะแสดงเป็นแฮช SHA-256 ในพาธการจัดเก็บและการนำเข้าปัจจุบัน ซึ่งหลีกเลี่ยงการเก็บค่าดิบทั่วไปไว้สำหรับการจับคู่

การแฮชไม่เหมือนกับการเข้ารหัสทุกบันทึกของแอป และการจัดเก็บในเครื่องไม่ใช่การสำรองข้อมูล บุคคลที่เข้าถึงอุปกรณ์ที่ปลดล็อกอยู่อาจยังคงเห็นชื่อการแจ้งเตือน ตารางเวลา หรือประวัติผ่านแอป โทรศัพท์ที่สูญหายหรือรีเซ็ตอาจสูญเสียข้อมูลในเครื่องได้เช่นกัน เว้นแต่ผู้ใช้จะสร้างการส่งออก ดู [การสำรองข้อมูลและการแชร์](../guides/backup-and-sharing.md) สำหรับรูปแบบและวัตถุประสงค์ที่แตกต่างกัน

นโยบายความเป็นส่วนตัวระบุว่าการวิเคราะห์แบบเลือกปิดอยู่โดยค่าเริ่มต้น และอธิบายการจัดการข้อมูลรวมหากเปิดใช้งาน เอกสารนี้จึงไม่อ้างคำกล่าวที่กว้างกว่าว่าแอปไม่สามารถสื่อสารผ่านเครือข่ายได้ มันระบุข้อเท็จจริงที่ตรวจสอบแล้วที่แคบกว่า: การทำงานหลักและข้อมูลเป็นแบบในเครื่อง ไม่ต้องการบัญชีผลิตภัณฑ์ และไม่พบการพึ่งพา SDK โฆษณาในโปรเจกต์ที่ตรวจสอบ

## ความน่าเชื่อถือเป็นความรับผิดชอบร่วมกัน

BarcodeWake สามารถกำหนดเวลาและแสดงการแจ้งเตือน แต่ระบบปฏิบัติการเป็นผู้ตัดสินใจว่างานเบื้องหลังสามารถทำงานเมื่อใดและการหยุดชะงักใดที่ได้รับอนุญาต สิทธิ์การแจ้งเตือน การเข้าถึงการแจ้งเตือนแบบแม่นยำ โหมดเงียบหรือโฟกัส การปรับให้เหมาะสมแบตเตอรี่ การระงับแอปอัตโนมัติ และตัวจัดการงานของผู้ผลิต ล้วนมีความสำคัญ เครื่องมือความน่าเชื่อถือในแอปสามารถระบุความเสี่ยงของการกำหนดค่าและนำผู้ใช้ไปยังการตั้งค่า มันไม่สามารถแทนที่นโยบายของระบบได้

หลังติดตั้ง ให้ทดสอบโดยหน้าจอล็อกและโทรศัพท์อยู่ในโหมดพลังงานเดียวกับที่ใช้ข้ามคืน ทำซ้ำการทดสอบนั้นหลังอัปเดตระบบ การเปลี่ยนแปลงตัวประหยัดแบตเตอรี่ หรือการติดตั้งแอปใหม่ รักษาอุปกรณ์ให้ชาร์จ ระดับเสียงเหมาะสม และภารกิจที่เลือกพร้อมใช้งานจริง ปฏิบัติตาม [การแก้ไขปัญหาการส่งการแจ้งเตือน](../help/alarm-delivery.md) เมื่อการทดสอบล้มเหลว

## สิ่งที่ความเป็นส่วนตัวและความน่าเชื่อถือไม่สัญญา

BarcodeWake ไม่ใช่อุปกรณ์ทางการแพทย์ บริการแจ้งเหตุฉุกเฉิน หรือตัวติดตามขั้นการนอน ไม่มีแอปแจ้งเตือนใดสามารถรับประกันการตื่นหรือชดเชยสำหรับอุปกรณ์ที่ไม่พร้อมใช้งาน หน้า [ข้อเท็จจริงและข้อจำกัด](../facts.md) แสดงรายการขอบเขตเหล่านี้ ในขณะที่ [ความพร้อมใช้งาน](../availability.md) แยกหลักฐานร้านค้าสาธารณะออกจากความสามารถของแหล่งที่มาที่ใหม่กว่า
