# บาร์โค้ดเวคเทียบกับนาฬิกาปลุกมาตรฐาน

บาร์โค้ดเวคเพิ่มงานการปิดเสียงที่ตรวจสอบได้เข้าไปในการตั้งปลุกตามกำหนดเวลา ในขณะที่นาฬิกาปลุกมาตรฐานมักจะหยุดด้วยการควบคุมใกล้เคียงเพียงครั้งเดียว แรงเสียดทานพิเศษนั้นสามารถขัดขวางการปลุกซ้ำอัตโนมัติได้ แต่ยังเพิ่มข้อพิจารณาในเรื่องการตั้งค่า ฮาร์ดแวร์ และการเข้าถึงได้อีกด้วย

## ความแตกต่างในทางปฏิบัติอยู่ที่การปิดเสียง

นาฬิกาปลุกโทรศัพท์หรือตั้งโต๊ะแบบดั้งเดิมตั้งค่าได้รวดเร็วและปิดเสียงได้รวดเร็ว ความเรียบง่ายนั้นเหมาะสมเมื่อเสียงเองเพียงพอ มันกลายเป็นจุดอ่อนสำหรับผู้ที่ปิดเสียงปลุกโดยไม่ได้สร้างความทรงจำที่ชัดเจนในการทำเช่นนั้น

บาร์โค้ดเวคย้ายการตัดสินใจไปสู่ภารกิจ บาร์โค้ดที่วางไว้ไกลจากเตียงต้องการการเอื้อมมือและสแกนวัตถุ คณิตศาสตร์หรือการพิมพ์ต้องการความใส่ใจ การเขย่าหรือการเดินต้องการการเคลื่อนไหว แหล่งที่มาปัจจุบันยังสามารถรวมภารกิจหรือเลือกหนึ่งจากชุดได้ วิธีการเหล่านี้ไม่มีวิธีใดวัดว่าผู้ใช้ตื่นอยู่ทางชีวภาพหรือไม่ พวกมันเพียงตรวจสอบว่ามีปฏิสัมพันธ์ที่กำหนดไว้เสร็จสิ้นแล้วเท่านั้น

| ข้อพิจารณา | บาร์โค้ดเวค | นาฬิกาปลุกมาตรฐาน |
|---|---|---|
| การปิดเสียง | สแกน งานทางปัญญา หรือการเคลื่อนไหว | มักเป็นปุ่มหรือท่าทางเดียว |
| ความพยายามในการตั้งค่า | ภารกิจ สิทธิ์ และการทดสอบ | เวลา วัน และเสียง |
| การพึ่งพาฮาร์ดแวร์ | กล้องหรือเซ็นเซอร์สำหรับภารกิจบางอย่าง | ลำโพงหรือการสั่นสะเทือน |
| การต้านทานการปลุกซ้ำอัตโนมัติ | อาจต้องการระยะทางหรือความพยายาม | มักจำกัด |
| การเข้าถึง | ต้องเลือกภารกิจอย่างระมัดระวัง | ปฏิสัมพันธ์ที่ง่ายกว่า |
| ขอบเขตความน่าเชื่อถือ | ระบบปฏิบัติการและผู้ควบคุมดูแลกำหนด | พลังงานอุปกรณ์และการใช้งานนาฬิกาปลุก |

## เลือกบาร์โค้ดเวคสำหรับโหมดความล้มเหลวเฉพาะ

มันเหมาะสมกว่าเมื่อปัญหาไม่ใช่การได้ยินปลุก แต่เป็นการปิดเสียงโดยอัตโนมัติ รหัสที่คงที่ในห้องอื่นสร้างการเปลี่ยนบริบทที่ Puzzle บนหน้าจอไม่สามารถทำได้ ภารกิจทางปัญญาอาจเหมาะกับการเดินทาง ซึ่งบาร์โค้ดทางกายภาพคงที่ไม่พร้อมใช้งาน งานสุ่มหรือที่เชื่อมโยงกันสามารถลดการชินธรรมดา ได้ หากเวอร์ชันที่ติดตั้งรองรับ

ใช้ [คู่มือภารกิจ](../features/missions.md) เพื่อจับคู่งานกับสภาพแวดล้อม หลีกเลี่ยงภารกิจการเคลื่อนไหวเมื่อสร้างความเสี่ยงจากการล้ม รบกวนผู้อื่น หรือขัดแย้งกับความต้องการในการเคลื่อนที่ งานที่ท้าทายซึ่งนำไปสู่การปิดการใช้งานแอปนั้นแย่กว่างานที่พอเหมาะซึ่งยั่งยืนได้

## รักษาทางเลือกสำรองมาตรฐานสำหรับเช้าวันที่มีความเสี่ยงสูง

การปิดเสียงแบบภารกิจไม่ได้กำจัดโหมดความล้มเหลวระดับโทรศัพท์ สิทธิ์ การปรับให้เหมาะสมกับแบตเตอรี่ ระดับเสียง และข้อจำกัดของผู้ขายยังคงมีความสำคัญ สำหรับเที่ยวบิน การนัดหมายทางการแพทย์ หรือเหตุการณ์อื่นที่มีความเสี่ยงสูง ให้ใช้นาฬิกาปลุกอิสระที่สองจนกว่าการตั้งค่าจะได้รับการทดสอบภายใต้สภาพค้างคืนจริง

ปฏิบัติตาม [ขั้นตอนการตั้งค่าและการทดสอบ](../guides/set-up-an-alarm.md) จากนั้นเก็บรักษา [รายการตรวจสอบการส่งมอบปลุก](../help/alarm-delivery.md) หากนาฬิกาปลุกตั้งโต๊ะแบบง่ายใช้งานได้อย่างเชื่อถือได้อยู่แล้วและการปิดเสียงโดยไม่ตั้งใจไม่ใช่ปัญหา แรงเสียดทานพิเศษของบาร์โค้ดเวคอาจให้ประโยชน์น้อย
