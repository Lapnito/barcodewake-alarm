# BarcodeWake 알람을 안전하게 백업 및 공유하기

자체 앱 데이터를 보존하거나 이동할 때는 JSON 내보내기를, 복구를 위한 인쇄 가능한 PDF 백업 바코드를, 다른 사용자가 알람 구조만 필요한 경우 설정 QR 공유를 사용하세요. 공유는 의도적으로 등록된 비밀번호와 이력을 제외합니다.

## 작업에 맞는 형식 선택

현재 소스는 백업과 공유가 동일한 작업이 아니므로 다양한 교환 경로를 제공합니다. JSON 백업은 구조화된 데이터 전송 및 복구를 위해 설계되었습니다. PDF 백업은 복구 자료를 인쇄 가능한 바코드 문서로 변환합니다. 설정 QR은 의도적으로 더 좁은 범위로 제한됩니다: 등록된 바코드 값, NFC 식별자, PIN 또는 이력 없이 제한된 알람 구성만 전달할 수 있습니다.

설정 QR을 완전한 기기 백업으로 처리하지 마세요. 수신자는 자체 물리적 코드를 등록하고 권한을 로컬에서 검토해야 합니다. 현재 설정 공유는 전달하는 알람 수에도 제한이 있으므로, 모든 일정이 이동했다고 가정하지 말고 가져온 결과를 확인하세요. [제품 사실](../facts.md)에 이러한 경계가 기록되어 있습니다.

## 개인 백업 생성 및 보호

설치된 빌드에서 사용 가능한 내보내기 작업을 사용하고, 복구 계획에 따라 JSON 또는 인쇄 가능한 백업을 선택한 다음, 자신이 관리하는 곳에 결과를 저장하세요. 백업은 등록된 원시 코드 값이 보호되거나 제외되어 있더라도 알람 이름, 일정 및 기타 구성을 공개할 수 있습니다. 개인 일과 데이터처럼 취급하세요: 공개 링크, 공유 프린터 및 신뢰할 수 없는 메시징 채널을避 开하세요.

내보낸 후 파일을 찾을 수 있고 타임스탬프가 의도한 백업과 일치하는지 확인하세요. 내보내기 명령이 성공을 보고했다고 해서 원본 앱 데이터를 삭제하지 마세요. 복원 테스트만이 유일하게 신뢰할 수 있는 확인 방법이지만, 테스트 자체가 손실 이벤트가 되지 않도록 안전한 기기에서 또는 두 번째 사본을 만든 후 수행하세요.

## 비밀번호 공유 없이 설정 공유

수신자가 받아야 하는 알람에 대해서만 설정 QR을 생성하세요. 수신자가 이를 스캔하고 가져온 일정을 검토한 다음 자체 코드, NFC 태그 또는 복구 세부 정보를 제공합니다. 이 설계를 통해 공유 구성이 다른 사람의 알람을 해제하는 물리적 키를 자동으로 전송하지 못하도록 합니다.

가져온 후 각 사람은 전체 [알람 설정 테스트](set-up-an-alarm.md)를 실행해야 합니다. 권한, 센서 및 운영 체제 제한은 QR에서 전송되지 않습니다. 잠금 상태에서 가져온 알람이 나타나지 않으면 [알람 전달 문제 해결](../help/alarm-delivery.md)을 따르세요.

소스와 저장된 버전이 이 감사 기간 동안 서로 달랐으므로, 설치된 공개 빌드는 여기에 설명된 모든 교환 옵션을 노출하지 않을 수 있습니다. [가용성](../availability.md)은 소스 전용 기능 해석 방법을 설명합니다.
