# BarcodeWake 術語

BarcodeWake 使用「任務」來表示解除鬧鐘所需的動作。掃描任務會驗證已註冊的實體碼；挑戰任務會驗證答案或動作；分享和備份則指不同的交換格式。

## 鬧鐘與任務術語

- 鬧鐘：具有時間、啟用日期、聲音和關閉配置的排程喚醒事件。
- 任務：關閉前必須完成的任務。
- 掃描任務：與已註冊的碼表示形式比對的條碼、QR 碼或 NFC 任務。
- 挑戰任務：數學、打字、搖晃或步數任務。
- 單一模式：一個配置的任務在鬧鐘上運行。
- 鏈結模式：配置的任務按選擇的順序運行。
- 隨機模式：從配置的集合中選擇一個任務。
- 難度：改變任務需求的任務設定；其確切效果取決於任務類型。

## 數據和可靠性術語

- 已註冊的碼：與掃描任務關聯的實體條碼、QR 碼或 NFC 標籤。
- 碼雜湊值：用於當前儲存和交換路徑中比對已註冊值的一種單向 SHA-256 表示形式。
- 本地備份：一種匯出的表示形式，旨在保存或恢復應用程式資料。
- 設定 QR 碼：一種有限的設定檔分享格式，會省略已註冊的碼、NFC 識別碼、PIN 碼和歷史記錄。
- 可靠性醫生：用於權限和系統設定的應用程式內診斷，可能會干擾鬧鐘傳遞。
- 精確鬧鐘存取：Android 系統權限或政策，允許時間關鍵的排程。
- 電池優化：可能限制背景執行的作業系統或供應商控制。
