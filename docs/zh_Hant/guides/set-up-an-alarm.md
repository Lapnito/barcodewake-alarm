# 如何設定 BarcodeWake 鬧鐘

先建立行程，選擇安全且實用的任務，授予必要的權限，然後進行近期的鎖定螢幕測試。對於掃描任務，請註冊一個耐用的物品，該物品在鬧鐘響起時能夠取得並可讀取。

## 先選擇任務，再選擇物品

決定什麼動作能區分起床與取消。放在另一個房間的條碼會產生物理距離。數學或打字可以增加專注且不需要相機。搖晃或步數會增加活動，但取決於感測器，且可能不適合每個人或環境。[任務參考](../features/missions.md)說明單一、鏈結和隨機模式之間的取捨。

如果使用條碼、QR 碼或 NFC 標籤，請選擇耐用的物品。避免一次性包裝、家庭成員可能移動的物品，或在旅行時無法取得的代碼。檢查相機是否能在預期的光線下對焦。NFC 需要相容的手機和標籤。

## 設定行程和取消規則

打開鬧鐘編輯器，設定想要的時間和啟用日期，然後選擇已安裝版本顯示的任務。第一次測試時請保守地設定難度或目標。如果已安裝的版本支援鏈結，請按照可以安全完成的順序排列任務，避免匆忙穿越樓梯或離開安全區域。

從任務設定流程中註冊實體代碼。為鬧鐘設定標籤以標識預期的作息，而不是暴露敏感資訊。檢查已安裝版本中可見的音量、震動和任何鬧鐘後續選項。可用的控制選項可能有所不同，因為[公開版和原始碼版本](../availability.md)在審核日期時並不相同。

## 出於目的授予權限

允許通知傳遞所需的通知和鬧鐘相關存取。僅在使用掃描任務時授予相機存取權，並在所選任務需要時授予感測器存取權。在 Android 上，如果應用程式的可靠性檢查標記這些項目，請檢查精確鬧鐘和電池設定。不要假設儲存鬧鐘就證明允許背景傳遞。

## 測試完整過夜路徑

設定幾分鐘後的測試。鎖定螢幕，將 BarcodeWake 留在背景中，並將手機置於與過夜計劃相同的聲音和電源狀態。確認鬧鐘出現、音訊可聽見，並且可以完成所選的任務。然後在將註冊的物品移至實際位置後重複測試。

如果傳遞失敗，請使用[鬧鐘傳遞檢查清單](../help/alarm-delivery.md)。如果成功，請在設定穩定後考慮建立[本地備份](backup-and-sharing.md)。
