# BarcodeWake 事实与限制

BarcodeWake 排程鬧鐘並驗證所選的關閉任務。它可以使用掃描、認知挑戰或動作，將記錄的核心資料儲存在本機，不需要產品帳戶，且不進行睡眠階段分析。

## 产品概览

| 问题 | 已驗證的回答 |
|---|---|
| 這是什麼？ | 一個具有身體和認知任務關閉功能的鬧鐘。 |
| 目前原始碼中有哪些任務？ | 條碼、QR 碼、數學、打字、搖晃和步數。NFC 被作為已註冊的程式碼路徑處理。 |
| 需要帳戶嗎？ | 所記錄的功能沒有帳戶或登入流程。 |
| 資料保存在哪裡？ | 鬧鐘配置、歷史記錄和偏好設定使用本機儲存。當前程式碼路徑會對已註冊的程式碼值進行雜湊處理。 |
| 這是睡眠追蹤器嗎？ | 不是。它排程鬧鐘並驗證任務；它不會對睡眠階段進行分類。 |
| 每個原始碼功能都已公開發布嗎？ | 未確定。在審計日期時，商店版本和原始碼版本不同。 |

## 實務上重要的限制

鬧鐘應用程式在手機層級的限制內運作。通知權限、精確鬧鐘存取、專注模式、電池優化和製造商特定的背景控制都可能影響鬧鐘是否如預期到達。BarcodeWake 包含可靠性檢查和指導，但應用程式無法覆寫每個作業系統或製造商的限制。在安裝後和主要系統變更後測試鬧鐘；[交付檢查清單](help/alarm-delivery.md) 說明了如何操作。

任務硬體也很重要。掃描需要相機存取權和可讀取的實體條碼。搖晃和步數任務取決於相關感測器。NFC 需要相容的硬體。複製或損壞的標籤可能導致無法配對，因此請保持復原路徑，且不要讓唯一註冊的物件無法存取。
