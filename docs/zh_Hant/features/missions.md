# BarcodeWake 任務與任務鏈

BarcodeWake 任務是用來關閉鬧鐘的條件。目前來源支援條碼、QR 碼、數學、打字、搖晃和步數任務，已註冊的 NFC 透過程式碼掃描路徑處理。任務可以單獨執行、按順序執行或隨機選擇執行。

## 掃描任務創造身體距離

條碼或 QR 碼任務會將即時相機掃描與設定期間註冊的程式碼進行比較。程式碼可以放在手臂觸及不到的物品上：浴室裡的盥洗用品、廚房裡的早餐物品，或光線充足區域中的其他穩定物品。NFC 透過相容標籤和裝置遵循相同的概念。應用程式在目前路徑中儲存雜湊表示法，而不需要原始程式碼進行一般比較。

選擇鬧鐘響起時仍然可用的物品。包裝會被丟棄、標籤會褪色，旅行會改變環境。在唯一可能需要替換的藥盒上註冊程式碼，不如使用耐用的標籤來得穩健。[鬧鐘設定指南](../guides/set-up-an-alarm.md) 涵蓋放置和測試。

## 挑戰任務以努力換取移動

數學和打字需要專注輸入。搖晃和步數需要身體移動以及支援的感應器。難度和目標設定會改變預期的工作量，但較難的任務並不一定比較好。過度的摩擦可能會鼓勵完全停用鬧鐘，而簡單的任務在重複後可能會變得自動化。

將任務與失敗模式相匹配。如果在半夢半醒時會關掉鬧鐘，在另一個房間掃描會創造有用的距離。如果相機存取不方便，較短的打字或數學任務可能更實用。如果有行動能力、平衡或無障礙方面的考量，請避免基於移動的任務，選擇可以安全完成的任務。

## 單一、鏈結和隨機模式

單一模式要求完成一個已設定的任務。鏈結模式按順序執行多個已設定的任務。隨機模式從已設定的集合中選擇，減少單一記憶互動變得自動化的機會。這些模式存在於較新的已檢查來源中；[可用性](../availability.md) 解釋了為何這不能證明它們已經在每個公開版本中。

變更模式、權限或註冊物件後，請務必執行近程測試。保持所選物品可觸及，並提供安全的恢復路徑。對於與任務完成無關的傳遞問題，請使用[可靠性檢查清單](../help/alarm-delivery.md)。
