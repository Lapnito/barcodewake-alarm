# So richten Sie einen BarcodeWake-Alarm ein

Erstellen Sie zuerst den Zeitplan, wählen Sie eine sichere und praktische Mission, erteilen Sie die erforderlichen Berechtigungen und führen Sie dann einen Test mit gesperrtem Bildschirm in naher Zukunft durch. Für Scan-Missionen registrieren Sie ein dauerhaftes Objekt, das verfügbar und lesbar sein wird, wenn der Alarm ertönt.

## Wählen Sie die Mission vor dem Objekt

Entscheiden Sie, welche Aktion das Aufwecken vom Ablehnen trennen soll. Ein Barcode in einem anderen Raum schafft physische Distanz. Mathe oder Tippen fügt Konzentration hinzu, ohne eine Kamera zu benötigen. Schütteln oder Schritte fügen Bewegung hinzu, hängen aber von Sensoren ab und sind möglicherweise nicht für jede Person oder Umgebung geeignet. Die [Mission-Referenz](../features/missions.md) erklärt die Kompromisse zwischen Einzel-, Ketten- und Zufallsmodi.

Wenn Sie einen Barcode, QR-Code oder NFC-Tag verwenden, wählen Sie etwas Dauerhaftes. Vermeiden Sie Einwegverpackungen, ein Objekt, das ein anderes Haushaltsmitglied möglicherweise bewegt, oder einen Code, der während der Reise nicht zugänglich sein wird. Überprüfen Sie, ob die Kamera im erwarteten Licht fokussieren kann. NFC benötigt ein kompatibles Telefon und einen Tag.

## Konfigurieren Sie den Zeitplan und die Schieberegel

Öffnen Sie den Alarm-Editor, stellen Sie die gewünschte Zeit und aktive Tage ein und wählen Sie dann die von der installierten Version angezeigte Mission. Konfigurieren Sie deren Schwierigkeit oder Ziel für den ersten Test konservativ. Wenn die installierte Version Ketten unterstützt, ordnen Sie Missionen in einer Reihenfolge an, die sicher erledigt werden kann, ohne über Treppen zu eilen oder einen sicheren Bereich zu verlassen.

Registrieren Sie den physischen Code aus dem Mission-Setup-Flow. Geben Sie dem Alarm ein Etikett, das die beabsichtigte Routine identifiziert, anstatt sensible Informationen preiszugeben. Überprüfen Sie Lautstärke, Vibration und alle Aufwach-Nachfolge-Optionen, die in der installierten Version sichtbar sind. Verfügbare Steuerungen können unterschiedlich sein, da die [öffentlichen und Quellversionen](../availability.md) zum Prüfdatum nicht identisch waren.

## Erteilen Sie Berechtigungen mit einem Zweck

Erlauben Sie Benachrichtigungen und alarmbezogenen Zugriff, der für die Lieferung erforderlich ist. Erteilen Sie nur bei Verwendung einer Scan-Mission Kamerazugriff und Sensorzugriff, wenn die gewählte Mission diesen benötigt. Überprüfen Sie auf Android genaue Alarm- und Batterieeinstellungen, wenn die Zuverlässigkeitsprüfung der App diese markiert. Gehen Sie nicht davon aus, dass das Speichern eines Alarms beweist, dass die Hintergrundleferung erlaubt ist.

## Testen Sie den vollständigen nächtlichen Weg

Stellen Sie einen Test einige Minuten im Voraus ein. Sperren Sie den Bildschirm, lassen Sie BarcodeWake im Hintergrund und versetzen Sie das Telefon in denselben Ton- und Stromzustand, der für die Nacht geplant ist. Bestätigen Sie, dass der Alarm erscheint, der Ton hörbar ist und die genau ausgewählte Mission abgeschlossen werden kann. Wiederholen Sie dies dann, nachdem Sie das registrierte Objekt an seinen tatsächlichen Standort bewegt haben.

Wenn die Lieferung fehlschlägt, verwenden Sie die [Alarmlieferungs-Checkliste](../help/alarm-delivery.md). Wenn sie erfolgreich ist, erwägen Sie die Erstellung einer [lokalen Sicherung](backup-and-sharing.md), nachdem das Setup stabil ist.
