# BarcodeWake gegen einen Standard-Wecker

BarcodeWake fügt einem geplanten Alarm eine überprüfbare Ausschaltaufgabe hinzu, während ein Standard-Wecker normalerweise mit einer nahegelegenen Steuerung stoppt. Diese zusätzliche Reibung kann automatisches Schlummern unterbrechen, bringt aber auch Überlegungen zu Einrichtung, Hardware und Barrierefreiheit mit sich.

## Der praktische Unterschied liegt beim Ausschalten

Ein herkömmlicher Telefon- oder Nachttischwecker lässt sich schnell einstellen und schnell stummschalten. Diese Einfachheit ist angemessen, wenn der Ton selbst ausreicht. Sie wird zum Nachteil für jemanden, der Alarme ausschaltet, ohne eine klare Erinnerung daran zu bilden.

BarcodeWake verlagert die Entscheidung in eine Aufgabe. Ein Barcode, der entfernt vom Bett platziert ist, erfordert das Greifen und Scannen eines Objekts. Mathe oder Tippen erfordern Aufmerksamkeit. Schütteln oder Schritte erfordern Bewegung. Die aktuelle Quelle kann auch Aufgaben kombinieren oder eine aus einem Set auswählen. Keine dieser Methoden misst, ob der Benutzer biologisch wach ist; sie verifizieren nur, dass eine definierte Interaktion abgeschlossen wurde.

| Überlegung | BarcodeWake | Standard-Wecker |
|---|---|---|
| Ausschalten | Scannen, kognitive Aufgabe oder Bewegung | Normalerweise eine Taste oder Geste |
| Einrichtungsaufwand | Aufgabe, Berechtigungen und Testen | Zeit, Tage und Ton |
| Hardware-Abhängigkeit | Kamera oder Sensoren für einige Aufgaben | Lautsprecher oder Vibration |
| Automatischer Schlummer-Widerstand | Kann Entfernung oder Aufwand erfordern | Normalerweise begrenzt |
| Barrierefreiheit | Aufgabe muss sorgfältig ausgewählt werden | Einfachere Interaktion |
| Zuverlässigkeitsgrenze | Betriebssystem und Herstellerkontrollen | Gerätestrom und Alarmimplementierung |

## Wählen Sie BarcodeWake für einen spezifischen Fehlermodus

Es passt besser, wenn das Problem nicht im Hören des Alarms liegt, sondern im automatischen Ausschalten. Ein stabiler Code in einem anderen Raum schafft einen Kontextwechsel, den ein Rätsel auf dem Bildschirm nicht kann. Eine kognitive Aufgabe kann sich für Reisen eignen, wo ein dauerhafter physischer Code nicht verfügbar ist. Zufällige oder verkettete Aufgaben können die Gewöhnung reduzieren, wenn die installierte Version sie unterstützt.

Verwenden Sie den [Aufgabenleitfaden](../features/missions.md), um die Aufgabe an die Umgebung anzupassen. Vermeiden Sie Bewegungsmissionen, wenn sie Sturzgefahr schaffen, andere stören oder mit Mobilitätsbedürfnissen kollidieren. Eine anspruchsvolle Aufgabe, die zur Deaktivierung der App führt, ist schlimmer als eine bescheidene Aufgabe, die nachhaltig bleibt.

## Behalten Sie einen Standard-Fallback für folgenreiche Morgen

Aufgabenbasiertes Ausschalten entfernt keine Telefon-Ebene-Fehlermodi. Berechtigungen, Batterieoptimierung, Lautstärke und Herstellereinschränkungen sind weiterhin relevant. Für Flüge, Arzttermine oder andere folgenreiche Ereignisse verwenden Sie einen zweiten unabhängigen Alarm, bis die Einrichtung unter realen Übernachtungsbedingungen getestet wurde.

Folgen Sie dem [Einrichtungs- und Testverfahren](../guides/set-up-an-alarm.md), dann behalten Sie die [Liefercheckliste](../help/alarm-delivery.md). Wenn ein einfacher Nachttischwecker bereits zuverlässig funktioniert und versehentliches Ausschalten nicht das Problem ist, bietet die zusätzliche Reibung von BarcodeWake möglicherweise wenig Nutzen.
