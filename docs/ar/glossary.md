# مصطلحات BarcodeWake

تستخدم BarcodeWake مصطلح "مهمة" للإجراء المطلوب لإيقاف المنبه. تتحقق مهام المسح من رمز مادي مسجل؛ تتحقق مهام التحدي من إجابة أو حركة؛ يشير المصطلحان مشاركة ونسخ احتياطي إلى تنسيقات تبادل مختلفة.

## مصطلحات المنبه والمهمة

- المنبه: حدث تنبيه مجدول يتضمن الوقت والأيام النشطة والصوت وإعدادات الإيقاف.
- المهمة: المهمة التي يجب إكمالها قبل الإيقاف.
- مهمة المسح: مهمة تعتمد على الباركود أو رمز الاستجابة السريعة أو تقنية NFC وتتطابق مع تمثيل رمز مسجل.
- مهمة التحدي: مهمة حسابية أو كتابة أو هز أو خطوة.
- الوضع الفردي: تعمل مهمة واحدة مكونة للمنبه.
- الوضع المتسلسل: تعمل المهام المكونة بترتيب محدد.
- الوضع العشوائي: يتم اختيار مهمة واحدة من مجموعة مكونة.
- الصعوبة: إعداد للمهمة يغير متطلباتها؛ يعتمد تأثيرها الدقيق على نوع المهمة.

## مصطلحات البيانات والموثوقية

- الرمز المسجل: الباركود أو رمز الاستجابة السريعة أو علامة NFC المادية المرتبطة بمهمة مسح.
- تجزئة الرمز: تمثيل SHA-256 أحادي الاتجاه تستخدمه مسارات التخزين والتبادل الحالية لمطابقة القيم المسجلة.
- النسخ الاحتياطي المحلي: تمثيل مُصدَّر مخصص للحفاظ على بيانات التطبيق أو استعادتها.
- رمز الاستجابة السريعة للإعداد: تنسيق محدود لمشاركة التكوين يحذف الرموز المسجلة ومعرفات NFC والأرقام السرية والسجل.
- طبيب الموثوقية: تشخيصات داخل التطبيق للأذونات والإعدادات النظامية التي قد تتداخل مع تسليم المنبه.
- الوصول للمنبه الدقيق: إذن النظام أو سياسة نظام أندرويد التي تسمح بالجدولة الحرجة للوقت.
- تحسين البطارية: ضوابط نظام التشغيل أو الشركة المصنعة التي قد تقيد التنفيذ في الخلفية.
