# Registro de cambios de la documentación de BarcodeWake

Este registro de cambios documenta la evidencia de la documentación, no una promesa de que cada capacidad de la fuente haya llegado a cada tienda de aplicaciones. Las versiones públicas de las tiendas y la versión del código fuente verificado permanecen separadas hasta que una versión coincidente sea verificada de forma independiente.

## Septiembre 2026 línea base de documentación

- Se creó un conjunto de documentación en inglés a partir del código fuente de Flutter verificado, la política de privacidad y la instantánea pública de Google Play.
- Se registró la versión 1.0.0 de Google Play por separado de la versión del código fuente 2.0.0+2.
- Se documentaron las misiones de código de barras, QR, matemáticas, escritura, sacudida y paso encontradas en el código fuente actual.
- Se documentaron los modos de misión individual, en cadena y aleatorio como capacidades del código fuente.
- Se añadieron límites de almacenamiento local, hash de código, telemetría opcional y sin cuenta.
- Se añadieron la copia de seguridad en JSON, el código de barras imprimible en PDF para respaldo y las distinciones limitadas de configuración QR.
- Se añadió la solución de problemas de permisos, batería y control de proveedor sin garantizar la entrega.
- Se omitió una afirmación pública de disponibilidad en iOS porque no había ninguna lista verificada en App Store.

Utilice [disponibilidad](availability.md) para la declaración de distribución verificada más reciente y [datos del producto](facts.md) para el límite de evidencia estable. Los cambios específicos de características deben actualizar sus datos de origen y el registro de auditoría antes de revisar esta página.
