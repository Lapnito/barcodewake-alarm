# BarcodeWake ミッションとミッションチェイン

BarcodeWake ミッションとは、アラームを解除する条件です。現在のソースでは、バーコード、QR、数学、入力、シェイク、ステップのタスクをサポートしており、登録されたNFCはコードスキャン経路で処理されます。ミッションは単独、順序、またはランダム選択で実行できます。

## スキャンMissionは物理的な距離を作成する

バーコードまたはQRコードミッションは、ライブカメラスキャンとセットアップ時に登録されたコードを比較します。コードは手の届かない位置的オブジェクトに配置できます：bathroomのトイレタリー、kitchenの朝食アイテム、または明るいエリアの安定したオブジェクト。NFCは互換性のあるタグとデバイスで同じ一般的なアイデアに従います。アプリ(current paths)にハッシュ表現が保存され、通常の比較に生のコードを必要としません。

アラームが鳴る時にまだ利用可能なオブジェクトを選んでください。包装は廃棄され、ラベルは色が落ち、旅行により環境が変わります。交換する必要がある唯一の薬箱にコードを登録することは、耐久性のあるラベルを使用するのより堅牢ではありません。[アラームセットアップガイド](../guides/set-up-an-alarm.md)には、配置とテストの項目が含まれています。

## 挑戦Missionは運動努力的代わりに動きを交換する

数学と入力は集中した入力を必要とします。シェイクとステップは身体的な運動とサポートされたセンサーを必要とします。難易度とターゲット設定は、どの程度の作業が期待されるかを変更しますが、より難しいミッションが自動的により良いわけではありません。過度な摩擦はアラーム全体を無効にすることを促す可能性があり、易しいタスクは反復後に自動的になる可能性があります。

タスクを失敗モードにマッチさせてください。眠りかけにアラームを切るする場合は、別の部屋でスキャンすると有用な距離を作成します。カメラへのアクセスが不便な場合は短い入力または数学タスクがより実用的かもしれません。移動性、バランス、またはアクセシビリティが懸念事項の場合は、移動ベースのミッションを避け安全に完了できるタスクを選んでください。

## シングル、チェーン、ランダムモード

シングルモードは1つの設定されたミッションを要求します。チェーンモードは順序でいくつかの設定されたミッションを実行します。ランダムモードは設定されたセットから選択し、1つの記憶されたインタラクションが自動的になる可能性を減らします。これらのモードは新しいチェックされたソースに存在し、[可用性](../availability.md)には、それですべての公開ビルドにすでに存在することが証明されていない理由が説明されています。

モード、パーミッション、または登録されたオブジェクトを変更した後、常に短期的なテストを実行してください。選択したオブジェクトに手が届くようにし、安全な回復ルートを提供してください。Mission完了に関連しない配送問題については、[信頼性チェックリスト](../help/alarm-delivery.md)を使用してください。
