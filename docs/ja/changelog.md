# BarcodeWake ドキュメント変更履歴

この変更履歴はドキュメントの証拠を記録ものであり、各ソースの機能がすべてのアプリストアに到達しているという約束ではありません。公開ストアバージョンと確認済みのソースバージョンは、一致するリリースが独立して検証されるまで別々のままです。

## 2026年9月のドキュメントベース

- 確認済みのFlutterソース、プライバシーポリシー、および公開Google Playスナップショットから英語のドキュメントセットを作成しました。
- Google Playバージョン1.0.0をソースバージョン2.0.0+2とは別途記録しました。
- 現在のソースで見つかったバーコード、QR、算術、入力、シェイク、ステップミッションを文書化しました。
- ソース機能としてシングル、チェーン、ランダムミッションのモードを文書化しました。
- ローカルストレージ、コードハッシュ化、オプションのテレメ트리、アカウント不要の境界を追加しました。
- JSONバックアップ、印刷可能なPDFバックアップバーコード、および限定的なセットアップQRの区別を追加しました。
- 権限、バッテリー、ベンダー管理のトラブルシューティングを追加しましたが、保証される配信を約束したわけではありません。
- 確認済みのApp Storeリスティングがなかったため、公的なiOS提供の主張を見送りました。

[入手可能性](availability.md) で確認済みの最新の配布声明を、[製品情報](facts.md) で安定した証拠の境界を確認してください。機能固有の変更は、このページが改訂される前にソース事実と監査記録を更新する必要があります。
