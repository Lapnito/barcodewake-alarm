# BarcodeWakeアラームの設定方法

起床と解除を分けるアクションを最初に決めてから、 安全で実用的なミッションを選び、必要な権限を付与し、短時間でロック画面を解除するテストを実行します。スキャンミッションの場合、アラームが鳴る時に利用可能で読み取り可能な永続オブジェクトを登録してください。

## オブジェクトより先にミッションを選ぶ

起床と解除を分離するアクションを決めます。他室のバーコードは物理的な距離を而生みます。数学やタイピングは、カメラがなくても集中力を必要とします。シェイクや歩数は動きを中添加しますが、センサー依存であり，所有人都や環境に適さない場合があります。[ミッションリファレンス](../features/missions.md)では、単一、チェーン、ランダムモード間のトレードオフについて説明しています。

バーコード、QRコード、NFCタグを使用する場合は、耐久性のあるものを選びます。一回性の包装、別の世帯員が移動する可能性のあるオブジェクト、または旅行中にアクセスできないコードは避けてください。想定される光環境でカメラがピント合わせできるか確認してください。NFCは互換性のある電話とタグが必要です。

## スケジュールと解除ルールの設定

アラームエディタを開き、希望の時刻とアクティブ日を設定してから、インストールされたビルドで表示されているミッションを選択してください。最初のテストでは難易度またはターゲットを控えめに設定してください。インストールされたバージョンがチェーンをサポートしている場合、階段を駆け下りたり、安全なエリアを離れることなく安全に完了できる順序でミッションを配置してください。

ミッションセットアップフローから物理コードを登録してください。アラームには機密情報を露出するのではなく、意図したルーティンを識別できるラベル付けてください。インストールされたビルドに表示される音量、振動、起床後のフォローアップオプションを確認してください。利用可能なコントロールは異なり場合があります，这是因为[パブリックバージョンとソースバージョン](../availability.md)가監査日に同一ではなかったためです。

## 目的を持って権限を付与する

配信に必要な通知とアラーム関連のアクセスを許可してください。カメラアクセスはスキャンミッションを使用する場合のみ、センサーアクセスは選択したミッションに必要な場合にのみ付与してください。Androidでは、アプリの信頼性チェックがフラグを立てた場合、正確なアラームとバッテリー設定を確認してください。アラームを保存してもバックグラウンド配信が許可されているとは限りません。

## 夜間パス全体のテスト

数分後にテストを設定してください。画面をロックし、BarcodeWakeをバックグラウンドに残し、电话を就寝中に予定されているの音と電力状態と同じ状態にします。アラームが表示され、オーディオが聞こえ、選択した正確なミッションが完了できることを確認してください。次に、登録オブジェクトを実際の場所に移動してから繰り返してください。

配信に失敗した場合は、[アラーム配信チェックリスト](../help/alarm-delivery.md)を使用してください。成功した場合、設定が安定した後、[ローカルバックアップ](backup-and-sharing.md)を作成することを検討してください。
