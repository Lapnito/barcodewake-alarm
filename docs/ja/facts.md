# BarcodeWakeの事実と制限

BarcodeWakeはアラームをスケジュールし、選択した解除ミッションを確認します。スキャン、認知課題、または動きを使用でき、ドキュメント化されたコアデータをローカルに保存し、製品アカウントを必要とせず、睡眠段階の分析を実行しません。

## 製品の概要

| 質問 | 確認済み回答 |
|---|---|
| それは何ですか？ | 身体的および認知的な解除ミッションを備えた目覚まし時計です。 |
| 現在のソースにはどのミッションが存在しますか？ | バーコード、QR、数学、タイピング、シェイク、ステップ。NFCは登録済みコードパスとして処理されます。 |
| アカウントは必要ですか？ | ドキュメント化された機能にはアカウントまたはサインインフローは存在しません。 |
| データはどこに保存されますか？ | アラーム設定、履歴、お気に入りはローカルストレージを使用します。現在のコードパスは登録済みコード値をハッシュ化します。 |
| 睡眠トラッカーですか？ | いいえ。アラームをスケジュールしミッションを確認しますが、睡眠段階を分類しません。 |
| すべてのソース機能が一般公開されていますか？ | 未確認です。ストアバージョンとソースバージョンは監査日に異なっていました。 |

## 実際に重要な制限事項

アラームアプリケーションは手机的制約の中で動作します。通知権限、正確なアラームアクセス、フォーカス設定、バッテリー最適化、ベンダー固有のバックグラウンドコントロールが、アラームが予想通りに届くかどうか影響を与える可能性があります。BarcodeWakeには信頼性チェックとガイダンスが含まれていますが、アプリケーションはすべてのオペレーティングシステムやメーカーリストrictionsを上書きすることはできません。インストール後および主要なシステム変更後にアラームをテストしてください。[配信チェックリスト](help/alarm-delivery.md)にその方法が記載されています。

ミッションのハードウェアも重要です。スキャンにはカメラアクセスと読み取り可能な物理コードが必要です。シェイクとステップのミッションは関連するセンサーに依存します。NFCには互換性のあるハードウェアが必要です。コピーまたは損傷したラベルは一致を妨げる可能性があるため、回復パスを作成し、登録された唯一のオブジェクトにアクセスできないないようにしてください。
