# BarcodeWake મિશનો અને મિશન ચેઇનો

BarcodeWake મિશન એ અલાર્મ દૂર કરવા માટે ઉપયોગમાં લેવાતી શરત છે. વર્તમાન સ્રોત barcode, QR, ગણિત, ટાઇપિંગ, શેક અને સ્ટેપ ટાસ્ક્સને સપોર્ટ કરે છે, જેમાં રજિસ્ટર્ડ NFC કોડ-સ્કેનિંગ પાથ દ્વારા હેન્ડલ કરવામાં આવે છે. મિશનો એકલા, ક્રમમાં અથવા રેન્ડમ પસંદગી દ્વારા ચલાવી શકાય છે.

## Scan મિશનો શારીરિક અંતર બનાવે છે

barcode અથવા QR મિશન સેટઅપ દરમિયાન રજિસ્ટર્ડ કોડ સાથે લાઇવ કેમેરા સ્કેનની તુલના કરે છે. કોડને હાથની પહોંચથી દૂર એક વસ્તુ પર મૂકી શકાય છે: બાથરૂમમાં ટોઇલેટ્રીઝ, કિચનમાં સવારનો ખોરાક, અથવા સારી રીતે પ્રકાશિત વિસ્તારમાં બીજી સ્થિર વસ્તુ. NFC સુંદ્રિય ટૅગ અને ઉપકરણ સાથે એ જ સામાન્ય વિચારને અનુસરે છે. સામાન્ય તુલના માટે કાચા કોડની જરૂર વિના, ઍપ વર્તમાન પાથમાં હેશ રિપ્રેઝન્ટેશન સંગ્રહે છે.

એવી વસ્તુ પસંદ કરો જે અલાર્મ વાગે ત્યારે હજુ પણ ઉપલબ્ધ હશે. પેકેજિંગ ફેંકી દેવામાં આવે છે, લેબલ્સ ફીકા પડે છે અને પ્રવાસ વાતાવરણ બદલે છે. એકમાત્ર દવાના બોક્સ પર કોડ રજિસ્ટર કરવો જે તમારે બદલવું પડી શકે છે તે ટકાઉ લેબલનો ઉપયોગ કરવા કરતાં ઓછું મજબૂત છે. [alarm setup guide](../guides/set-up-an-alarm.md) પ્લેસમેન્ટ અને ટેસ્ટિંગ આવરી લે છે.

## Challenge મિશનો પ્રયત્ન બદલે મૂવમેન્ટ આપે છે

ગણિત અને ટાઇપિંગ એકાગ્ર ઇનપુટ માંગે છે. શેક અને સ્ટેપ્સને શારીરિક મૂવમેન્ટ અને સપોર્ટેડ સેન્સર્સ જરૂરી છે. ડિફિકલ્ટી અને ટાર્ગેટ સેટિંગ્સ કેટલો પ્રયત્ન અપેક્ષિત છે તે બદલે છે, પરંતુ મુશ્કેલ મિશન સ્વચ્છેદ્યે સારું નથી. અધિક ઘર્ષણ અલાર્મને સંપૂર્ણપણે બંધ કરવાની પ્રેરણા આપી શકે છે, જ્યારે સરળ ટાસ્ક પુનરાવર્તન પછી સ્વચાલિત બની શકે છે.

નિષ્ફળતા મોડમાં ટાસ્કને મેળ ખાઓ. જો તમે અડધી નીંદરમાં અલાર્મ બંધ કરો છો, તો બીજા રૂમમાં સ્કેનિંગ ઉપયોગી અંતર બનાવે છે. જો કેમેરા ઍક્સેસ અસુવિધાજનક હોય, તો ટૂંકું ટાઇપિંગ અથવા ગણિતનું ટાસ્ક વધુ પ્રેક્ટિકલ હોઈ શકે છે. જો મોબિલિટી, સંતુલન અથવા ઍક્સેસિબિલિટી ચિંતા હોય, તો મૂવમેન્ટ-આધારિત મિશનોથી દૂર રહો અને એવો ટાસ્ક પસંદ કરો જે સુરક્ષિત રીતે પૂર્ણ કરી શકાય.

## Single, chain અને random modes

Single mode એક કોન્ફિગર્ડ મિશન માંગે છે. Chain mode ક્રમમાં ઘણા કોન્ફિગર્ડ મિશનો ચલાવે છે. Random mode કોન્ફિગર્ડ સેટમાંથી પસંદ કરે છે, એક મેમરાઇઝ્ડ ઇન્ટરેક્શન સ્વચાલિત બનવાની શક્યતાને ઘટાડે છે. આ modes નવીનતમ ચેક્ડ સોર્સમાં હાજર છે; [availability](../availability.md) સમજાવે છે કે આ શા માટે તેઓ પહેલેથી જ દરેક પબ્લિક બિલ્ડમાં છે તેનો પુરાવો નથી.

Mode, પરવાનગીઓ અથવા રજિસ્ટર્ડ ઑબ્જેક્ટ્સ બદલ્યા પછી હંમેશા અલ્પ-અવધિનું ટેસ્ટ ચલાવો. પસંદ કરેલી વસ્તુ પહોંચમાં રહે તેની ખાતરી કરો અને સુરક્ષિત રિકવરી માર્ગ પ્રદાન કરો. મિશન પૂર્ણતા સાથે સંબંધિત ન હોય તેવી ડિલિવરી સમસ્યાઓ માટે, [reliability checklist](../help/alarm-delivery.md) નો ઉપયોગ કરો.
