# Факти та обмеження BarcodeWake

BarcodeWake планує будильники та перевіряє обране завдання для відключення. Він може використовувати сканування, когнітивні випробування або рух, зберігає задокументовані основні дані локально, не вимагає облікового запису продукту та не виконує аналіз стадій сну.

## Основні факти про продукт на один погляд

| Питання | Перевірена відповідь |
|---|---|
| Що це таке? | Годинник-будильник із фізичними та когнітивними завданнями для відключення. |
| Які завдання існують у поточній версії вихідного коду? | Штрих-код, QR‑код, математика, введення тексту, струшування та кроки. NFC обробляється як зареєстрований шлях коду. |
| Чи потрібен обліковий запис? | Для задокументованих функцій обліковий запис або потік входу відсутні. |
| Де зберігаються дані? | Конфігурація будильника, історія та налаштування використовують локальне сховище. Поточні шляхи коду хешують значення зареєстрованого коду. |
| Чи це трекер сну? | Ні. Він планує будильники та перевіряє завдання; він не класифікує стадії сну. |
| Чи всі функції вихідного коду є публічно випущеними? | Не встановлено. Версії магазину та вихідного коду відрізнялися на дату аудиту. |

## Обмеження, що важливі на практиці

Додаток будильника працює в межах обмежень телефону. Дозвіл на сповіщення, доступ до точного будильника, налаштування фокусування, оптимізація батареї та специфічні для виробника фонові керування можуть впливати на те, чи надійде будильник, як очікувалося. BarcodeWake містить перевірки надійності та вказівки, але додаток не може обійти кожне обмеження операційної системи або виробника. Перевірте будильник після встановлення та після великих змін системи; [контрольний список доставки](help/alarm-delivery.md) пояснює, як це зробити.

Апаратне забезпечення завдання також важливе. Сканування потребує доступу до камери та читабельного фізичного коду. Завдання струшування та кроків залежать від відповідних датчиків. NFC потребує сумісного апаратного забезпечення. Скопійована або пошкоджена мітка може перешкоджати збігу, тому зберігайте резервний шлях і не робіть єдиний зареєстрований об'єкт недоступним.
