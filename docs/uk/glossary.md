# Термінологія BarcodeWake

BarcodeWake використовує «місію» для дії, яку потрібно виконати, щоб вимкнути будильник. Скан-місії перевіряють зареєстрований фізичний код; челлендж-місії перевіряють відповідь або рух; передавання та резервне копіювання стосуються різних форматів обміну.

## Терміни будильника та місії

- Будильник: запланована подія пробудження з налаштуваннями часу, активних днів, звуку та вимкнення.
- Місія: завдання, яке потрібно виконати перед вимкненням.
- Скан-місія: завдання на основі штрих-коду, QR-коду або NFC, яке зіставляється із зареєстрованим уявленням коду.
- Челлендж-місія: математичне, друкарське, стряхування або крокове завдання.
- Одиночний режим: одна налаштована місія виконується для будильника.
- Ланцюжковий режим: налаштовані місії виконуються у вибраному порядку.
- Випадковий режим: одна місія вибирається з налаштованого набору.
- Складність: налаштування місії, яке змінює вимоги до завдання; його точний ефект залежить від типу місії.

## Терміни даних та надійності

- Зареєстрований код: фізичний штрих-код, QR-код або NFC-мітка, пов'язана зі скан-місією.
- Хеш коду: одностороннє представлення SHA-256, яке використовується поточними шляхами зберігання та обміну для зіставлення зареєстрованих значень.
- Локальна резервна копія: експортоване представлення, призначене для збереження або відновлення даних програми.
- QR-налаштування: обмежений формат обміну конфігурацією, який не включає зареєстровані коди, ідентифікатори NFC, PIN-коди та історію.
- Доктор надійності: внутрішня діагностика дозволів та системних налаштувань, які можуть заважати доставці будильника.
- Доступ до точного будильника: дозвіл або політика системи Android, що дозволяє планування з критичним часом.
- Оптимізація батареї: елементи керування операційної системи або постачальника, які можуть обмежувати фонове виконання.
