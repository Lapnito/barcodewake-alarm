# Αποστολές και αλυσίδες αποστολών BarcodeWake

Μια αποστολή BarcodeWake είναι η συνθήκη που χρησιμοποιείται για να απορριφθεί ένα ξυπνητήρι. Η τρέχουσα πηγή υποστηρίζει εργασίες γραμμωτού κώδικα, QR, μαθηματικών, πληκτρολόγησης, κούνησης και βημάτων, με την καταχωρημένη NFC να χειρίζεται μέσω της διαδρομής σάρωσης κώδικα. Οι αποστολές μπορεί να εκτελούνται μόνες τους, διαδοχικά ή με τυχαία επιλογή.

## Οι αποστολές σάρωσης δημιουργούν φυσική απόσταση

Μια αποστολή γραμμωτού κώδικα ή QR συγκρίνει μια ζωντανή σάρωση κάμερας με έναν κωδικό που καταχωρήθηκε κατά τη ρύθμιση. Ο κωδικός μπορεί να τοποθετηθεί σε ένα αντικείμενο εκτός εμβέλειας χεριού: είδη τουαλέτας σε ένα μπάνιο, ένα αντικείμενο πρωινού σε μια κουζίνα, ή ένα άλλο σταθερό αντικείμενο σε μια καλά φωτισμένη περιοχή. Η NFC ακολουθεί την ίδια γενική ιδέα με μια συμβατή ετικέτα και συσκευή. Η εφαρμογή αποθηκεύει μια αναπαράσταση κατακερματισμού στις τρέχουσες διαδρομές αντί να χρειάζεται τον ακατέργαστο κωδικό για σύγκριση.

Επιλέξτε ένα αντικείμενο που θα είναι ακόμα διαθέσιμο όταν χτυπήσει το ξυπνητήρι. Η συσκευασία πετιέται, οι ετικέτες ξεθωριάζουν και τα ταξίδια αλλάζουν το περιβάλλον. Η καταχώρηση ενός κωδικού στο μόνο κουτί φαρμάκου που μπορεί να χρειαστεί να αντικαταστήσετε είναι λιγότερο αξιόπιστη από τη χρήση μιας ανθεκτικής ετικέτας. Ο [οδηγός ρύθμισης ξυπνητηριού](../guides/set-up-an-alarm.md) καλύπτει την τοποθέτηση και τη δοκιμή.

## Οι αποστολές πρόκλησης ανταλλάσσουν κίνηση με προσπάθεια

Τα μαθηματικά και η πληκτρολόγηση απαιτούν εστιασμένη εισαγωγή. Το κούνημα και τα βήματα απαιτούν σωματική κίνηση και υποστηριζόμενους αισθητήρες. Οι ρυθμίσεις δυσκολίας και στόχου αλλάζουν πόση δουλειά αναμένεται, αλλά μια δυσκολότερη αποστολή δεν είναι αυτόματα καλύτερη. Η υπερβολική τριβή μπορεί να ενθαρρύνει την απενεργοποίηση του ξυπνητηριού εντελώς, ενώ μια εύκολη εργασία μπορεί να γίνει αυτόματη μετά από επανάληψη.

Προσαρμόστε την εργασία στη λειτουργία αποτυχίας. Αν απενεργοποιείτε τα ξυπνητήρια μισοκοιμισμένοι, η σάρωση σε ένα άλλο δωμάτιο δημιουργεί χρήσιμη απόσταση. Αν η πρόσβαση στην κάμερα είναι άβολη, μια σύντομη εργασία πληκτρολόγησης ή μαθηματικών μπορεί να είναι πιο πρακτική. Αν η κινητικότητα, η ισορροπία ή η προσβασιμότητα είναι θέμα ανησυχίας, αποφύγετε τις αποστολές που βασίζονται στην κίνηση και επιλέξτε μια εργασία που μπορεί να ολοκληρωθεί με ασφάλεια.

## Μονές, αλυσιδωτές και τυχαίες λειτουργίες

Η μονή λειτουργία ζητά μια διαμορφωμένη αποστολή. Η αλυσιδωτή λειτουργία εκτελεί πολλές διαμορφωμένες αποστολές σε σειρά. Η τυχαία λειτουργία επιλέγει από ένα διαμορφωμένο σύνολο, μειώνοντας την πιθανότητα μια απομνημονευμένη αλληλεπίδραση να γίνει αυτόματη. Αυτές οι λειτουργίες υπάρχουν στην νεότερη ελεγμένη πηγή· η [διαθεσιμότητα](../availability.md) εξηγεί γιατί αυτό δεν αποδεικνύει ότι είναι ήδη σε κάθε δημόσια έκδοση.

Πάντα εκτελέστε μια δοκιμή κοντινού χρόνου μετά την αλλαγή λειτουργίας, δικαιωμάτων ή καταχωρημένων αντικειμένων. Κρατήστε το επιλεγμένο αντικείμενο προσβάσιμο και παρέχετε μια ασφαλή διαδρομή ανάκαμψης. Για ζητήματα παράδοσης που δεν σχετίζονται με την ολοκλήρωση της αποστολής, χρησιμοποιήστε τη [λίστα ελέγχου αξιοπιστίας](../help/alarm-delivery.md).
