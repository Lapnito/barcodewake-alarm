# BarcodeWake registro de cambios de documentación

Este registro de cambios documenta la evidencia de la documentación, no una promesa de que cada capacidad del código fuente haya llegado a cada tienda de aplicaciones. Las versiones públicas de la tienda y la versión del código fuente verificada permanecen separadas hasta que una versión coincidente sea verificada de forma independiente.

## Línea base de documentación de septiembre de 2026

- Se creó un conjunto de documentación en inglés a partir del código fuente de Flutter verificado, la política de privacidad y la instantánea pública de Google Play.
- Se registró la versión de Google Play 1.0.0 por separado de la versión del código fuente 2.0.0+2.
- Se documentaron las misiones de código de barras, QR, matemáticas, escritura, sacudida y pasos encontradas en el código fuente actual.
- Se documentaron los modos de misión individual, encadenada y aleatoria como capacidades del código fuente.
- Se añadieron almacenamiento local, hash de código, telemetría opcional y límites sin cuenta.
- Se añadió la copia de seguridad en JSON, el código de barras de respaldo imprimible en PDF y las distinciones de QR de configuración limitada.
- Se añadió la solución de problemas de permisos, batería y control del proveedor sin prometer entrega garantizada.
- Se omitió la afirmación pública de disponibilidad en iOS porque no había ninguna lista verificada en el App Store disponible.

Usa [disponibilidad](availability.md) para la última declaración verificada de distribución y [datos del producto](facts.md) para el límite estable de evidencia. Los cambios específicos de características deben actualizar sus datos de origen y el registro de auditoría antes de que esta página sea revisada.
